# Description

Слайдер мегалабораторий РТУ МИРЭА - это мультимедийное приложение, первая версия которого была создана для XIII Петербурского международного юридического форума (ПМЮФ25).

Приложение разрабатывалось для работы на тач-экранах с поддержкой FULL HD, 2k и 4k разрешением. В данном приложение можно пролистывать карточки мегалабораторий, знакомиться с их описанием, а также просматривать фотографии или виртуальные 3D-экскурсии, если они были доступны для конкретной мегалаборатории.
